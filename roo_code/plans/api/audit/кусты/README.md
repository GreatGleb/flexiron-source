# Кусты вопросов владельцу

Строки аудита, у которых источник «нигде», задаются владельцу не по одной, а **кустами**: один и
тот же вопрос повторяется в десятке доменов, и один ответ закрывает его везде. Здесь лежат сами
документы вопросов — с замерами, вариантами и рекомендацией; ответы уезжают в
[`00-решения-владельца.md`](../00-решения-владельца.md) под номерами П, а дословный текст ответа —
в `toDo/tasks/ready/<месяц>/taskNN`.

| [3 — настройки, которых нет, и арендаторы](3-настройки-и-арендаторы.md) | 27 | 8 | ждёт ответа |

документом.
