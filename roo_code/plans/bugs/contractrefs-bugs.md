# Находки по резолверу ссылок — `frontend_vue/src/services/contractRefs.ts`

Резолвер — машинная приёмка всех документов проекта: им проверяются контракт, аудиты, планы
и брифы прогонов. Его собственные дефекты тише всех остальных: он не падает, он молчит.

---

## БАГ-01 — ссылки на файлы с кириллическими именами не проверяются, и молча

**File:** `frontend_vue/src/services/contractRefs.ts:71`
**Severity:** High — проверка отсутствует там, где её считают работающей
**Источник:** нарезчик находок ночного прогона 2026-09-12, подтверждено отдельной пробой

### Problem

Регулярка адреса допускает только латиницу:

```
const REF = /([A-Za-z0-9_./-]*[A-Za-z0-9_-]\.(?:ts|tsx|vue|py|md|json|mjs))?:(\d+)(?:-(\d+))?/g
```

Проба на двух ссылках — латинской и кириллической:

```
$ cat /tmp/ref-test.md
Ссылка на латиницу: `frontend_vue/src/services/api.ts:1-5`
Ссылка на кириллицу: `roo_code/fix-run-2026-09-09/триаж.md:79`

$ cd frontend_vue && CONTRACT_REFS=/tmp/ref-test.md npx vitest run src/services/contractRefs.spec.ts
[ссылки] документов 1 · ссылок 1 · битых 0
```

Ссылок в файле две, резолвер нашёл **одну**. Вторая не признана битой — она не признана
ссылкой вовсе. «Битых 0» на таком документе означает «я ничего не проверил», а читается как
«всё верно».

Второй режим отказа хуже первого: имя с дефисом и цифрами резолвер разбирает **частично**.
`триаж-делта-2.md:10-21` он читает как путь `-2.md` и даёт ложное «нет файла» — то есть
краснеет там, где ошибки нет, и автор идёт чинить верную ссылку.

**Масштаб.** Кириллические имена в проекте несут документы прогонов и планов:
`очередь-работ.md`, `триаж.md`, `триаж-делта.md`, `триаж-делта-2.md`, `журнал-починки.md`,
`00-решения-владельца.md`, `вердикт-скептика-класс-2.md`, `план-ночного-прогона.md`.
Каждая ссылка на них из любого документа сегодня не проверена.

Обратное неверно и важно для понимания: сам документ с кириллическим именем проверяется
нормально — `CONTRACT_REFS=roo_code/plans/api/audit/00-решения-владельца.md` даёт 1101
ссылку. Дефект только в ссылках **на** такие файлы изнутри других документов.

### Fix

TBD — решение владельца: расширять ли класс символов на кириллицу (риск ложных срабатываний
на обычной прозе, где двоеточие соседствует с числом) или запретить кириллические имена
файлов в документах, переименовав существующие. Обходной путь, применённый в брифах прогона
2026-09-12, — писать «файл `<путь>`, строки N-M» без двоеточия — снимает ложную красноту, но
проверки не возвращает.
