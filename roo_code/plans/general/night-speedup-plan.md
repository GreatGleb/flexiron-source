## 2. Пункты

### П1. Сторож ночи — каждые 15 минут
Статус 2026-09-27: **сделано** в `fix/night-feedback` — журнал проверки
[`night-watchdog-2026-09-27.md`](../../roo-context/verify-runs/night-watchdog-2026-09-27.md).
Установка таймера и живая проба на настоящей ночи — за владельцем.
Цель: ни одного часа простоя без реакции.
- Скрипт по таймеру (systemd timer рядом с `roo_code/workflows/systemd/`), без модели. Признаки беды:
  супервизор мёртв до срока; `state.json` последнего `run-*` в `stopped`; нет новых событий в
  `journal.jsonl` дольше 30 мин (порог — замерить: самый долгий автор ночей 27.09 — 25 мин);
  порция за порцией без принятых задач.
- Известные поломки — лечить без модели:
  - остановка на приёмке с работой в checkout → `codex-night.py --retry-review <run-N>` (так спасена
    задача 27.09, см. `ca99fd1`), затем продолжение ночи с оставшимся временем;
  - супервизор умер, дерево чистое → перезапуск ночи на оставшееся время.
- Неизвестная поломка → headless Claude Code (`claude --print`, как у авторов) с логами и
  заданием: причина, правка в ветке с тестом, перезапуск. Не справился → ночь продолжается без
  этой задачи, причина — в `СВОДКА.md`.
- Каждое действие сторожа — строкой в журнал ночи: что увидел, что сделал.
- Готово, когда: тест на каждый признак беды (подделанный каталог ночи) и на каждое лечение;
  живая проба — убить супервизор посреди пробной ночи, сторож её поднимает.

### П2. Групповые проверки у ядра
Статус 2026-09-27: **отложено по замеру**, решение владельца. `npm run verify` у ядра —
0.6 мин на задачу (медиана, 17 задач ночей 27.09), а не 1–2 мин; `checks` задачи идут по
разу при любой схеме. Группа из 2 экономит ~0.6 мин на пачку. Брак на этапе checks — 1 из
11 забракованных (приёмка 7, работа 3). Группа требует ждать нескольких готовых задач — это
спорит с конвейером П3. Запрет автору гонять verify без цикла починки вреден: авторы ловили
им ошибки до ядра. Починку «в сессии автора» — вернуть внутрь конвейера, если брак на checks
вырастет.
Цель: checks ядра — один прогон на пачку готовых задач, а не на каждую.
- Автор гоняет только тесты СВОЕЙ задачи (секунды), не `npm run verify` — правка
  `aider-agent.py`/задания автора.
- Ядро: применило N готовых патчей → один `npm run verify` + checks всех задач. Зелёное → на
  приёмку все. Красное → виновник по файлу упавшего теста (outputs не пересекаются); не
  определился → деление пачки пополам и повтор.
- Красное виновника → ход на починку в ЕГО сессию aider (история чата сохраняется —
  `restore_chat_history`), не в чужую.
- Готово, когда: тесты «пачка зелёная», «виновник по файлу», «виновник делением», «починка в
  своей сессии»; замер — время checks на порцию до/после.

### П3. Автор не ждёт пачку
Статус 2026-09-27: **сделано** в `fix/night-feedback` — журнал проверки
[`night-pipeline-2026-09-27.md`](../../roo-context/verify-runs/night-pipeline-2026-09-27.md).
Замер простоя на настоящей ночи — за владельцем.
Цель: убрать простой быстрого автора (3–18 мин на пачку).
- Вместо «пачка → все по очереди» — конвейер: автор закончил → его задача в очередь проверок и
  приёмки, на его слот — следующая задача из `disjoint_batch` по уже занятым файлам.
- Инварианты не трогать: Git меняет только ядро, коммит по одной задаче, файлы вне задачи —
  брак одной задачи.
- Готово, когда: тест — быстрый автор берёт следующую задачу до конца медленного; тест —
  задача, читающая outputs незакоммиченной, не стартует.

## 4. Ловушки, найденные 26–27.09 — не наступать снова

- **Симлинк `node_modules` в worktree** уводит путь за корень → vite 403 на шрифты → все снимки
  автора красные. В worktree — копия (`f012667`).
- **`pkill -f <шаблон>` убивает собственную оболочку**, если шаблон есть в её командной строке
  (дважды код 144 за сессию). Искать `pgrep`, гасить по PID/группе.
- **`codex-night.py` живёт в своей группе процессов**: убийство группы обёртки его не гасит, а
  он ждёт авторов пачки. Гасить ядро по PID, авторов — по группам `aider-runner.py`.
- **Повтор приёмки** требует HEAD как при остановке: сначала `--retry-review`, слияния — после.
- **Перенумерация ссылок контроллером** лежит в checkout рядом с работой автора — при повторе
  это своя правка (`ca99fd1`).
- **Срок ночи фиксируется при старте** (`--hours`), на ходу не продлевается — только перезапуск.
- **Классификатор авто-режима Claude Code** не даёт сессии запускать ночь и тесты в
  `flexiron-source` — запуск и слияние в ночную ветку делает владелец (или сторож по таймеру).
- **Под нагрузкой тесты краснеют не там** — любой замер между прогонами начинать с проверки, что
  от прошлого не осталось vite/playwright.
