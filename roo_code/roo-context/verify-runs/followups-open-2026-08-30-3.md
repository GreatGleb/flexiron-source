# Список «открытые находки 2026-08-30», пункт 3 — размер `.status-pill`

Решение владельца, принятое снимком: вариант `suppliers_list.css` — крупнее и легче.
Регистр решался отдельно, тоже снимком: **заглавные**.

## Что было

Четыре непрефиксных объявления `.status-pill` в трёх наборах значений; побеждал файл,
впрыснутый последним. План говорил о двух — замер нашёл четыре.

| файл | значения |
|---|---|
| `admin/components/_status-pills.css` | `4px 10px` / 12 / 10px / 700 / uppercase |
| `admin/orders_list.css` | те же, дословная копия — и МЁРТВАЯ |
| `admin/suppliers_list.css` | `4px 12px` / 12 / 12px / 500 ← выбран |
| `erp-base.css` | `2px 9px` / 30 / .72rem / 700 |

Копия в `orders_list.css` мертва: на `/admin/orders` нет ни одной `.status-pill`, там
свой класс `order-status-pill`. Проверено локатором — элемент не найден за 90 с.

## Что сделано

Одно объявление в `admin/components/_status-pills.css` — он приходит глобально из
`admin-core.scss`, а `.status-pill` встречается только в админке (проверено грепом по
`views/public`, `layouts`). Туда же переехали три мобильных объявления из
`suppliers_list.css`, иначе на узких экранах пилюля осталась бы без уменьшения.

`text-transform: uppercase` написан ЯВНО. Раньше он доставался варианту B наследованием
от объявления в этом же файле; после сведения наследовать стало неоткуда, и молчание
сменило бы вид молча.

Из `erp-base.css` объявление убрано отдельным основанием: файл грузится из `main.ts`,
то есть и на публичных страницах, а класс админский.

## ЧЕГО НЕ СДЕЛАНО, и это надо знать

**Полный прогон e2e не доведён до конца.** Правка лежит в глобальном CSS, то есть по
`verify.md` это уровень 2 и требуется полный набор, причём дважды подряд.

Запускался трижды — в отдельном worktree со своим конфигом, там же после чистки
осиротевших браузеров, и из живого дерева со ШТАТНЫМ `playwright.config.ts`. Все три
раза темп 1–2 теста в минуту вместо ожидаемых шестидесяти: сегодня же на этой машине
чужой полный прогон прошёл за 17.4 минуты. При этом те же 96 визуальных тестов
отдельным прогоном идут за 3.3 минуты, то есть медленные не они.

На момент записи машина занята на 88 % процессора при swap 3.4 ГБ из 4 — прогон
работает, но доводить его до конца пришлось бы часами. Прогон оставлен идти; его итог
не входит в основания этого коммита.

Основания, которые ЕСТЬ: зелёный гейт, все 96 визуальных тестов против перезаписанных
эталонов, замер computed style на четырёх маршрутах и просмотр изменённых эталонов
глазами. Основания, которых НЕТ: полный набор из 1064 тестов.

**Вердикт: свип неполный — линза Л9 подтверждена частично (визуальный слой целиком,
полный набор нет).**
