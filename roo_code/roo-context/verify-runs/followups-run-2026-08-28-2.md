### 13. Соединить финансовый модуль с оплатами заказа — **ОТКЛОНЁН, ✅ НЕ СТАВЛЮ**

Коммиты `73df658` + `8d21ffb`, откачены `2820cc4` + `66b1e4a`, причина — в `followups-13.md`
коммитом `52903fd`.

Пункт требует не правила, а **сходимости двух представлений**: «частичная оплата видна как
есть — оплачено X из Y, ТОТ ЖЕ РАСЧЁТ, что уже живёт в карточке заказа». Заведён он ровно
затем, чтобы не было «двух несвязанных представлений об оплатах».

В коде связь оплаты со счётом необязательна и по умолчанию не ставится: `OrderCardPage.vue:734`
обнуляет `paymentInvoiceId` при открытии модалки, `:755` шлёт `invoiceId: … || null`,
`orders.ts:3775` кладёт `?? null` без подстановки открытого счёта, а реестр (`orders.ts:4299`)
считает оплаченным только `p.invoiceId === invoice.id`. Зонд приёмщика на настоящем коде —
один заказ, счёт 500, оплата 500, разница только в `invoiceId`:

```
attach=false | ORDER paidAmount=500 | REGISTRY paid=0   outstanding=500 status=overdue
attach=true  | ORDER paidAmount=500 | REGISTRY paid=500 outstanding=0   status=completed
```

То есть при штатном «Сохранить» карточка показывает деньги полученными, а «Входящие» рядом
рисуют по тому же документу «Просрочен» и «оплачено 0.00»; колокольчик при этом звонит
(`BELL before=2 after=4`) по счёту, оплаченному полностью. Это ровно та болезнь, ради которой
пункт заведён.

Подтверждено и переделывать не надо: граница просрочки = конец дня срока
