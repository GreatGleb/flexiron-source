## 0. Где гонялась приёмка и почему не в рабочем дереве

Рабочее дерево репозитория **грязное**: восемь файлов изменены или не добавлены, и ни одна
из этих правок не входит в ветку. Гонять приёмку там значило бы принимать не то, что человек
утром смержит.

```

Поэтому вся приёмка прогнана в отдельном рабочем дереве ровно на коммите ветки:

```
$ git worktree add --detach <scratch>/wt-accept c7e15c8
$ git -C <scratch>/wt-accept status --short
?? frontend_vue/node_modules        # симлинк на node_modules основного дерева, больше ничего
$ git -C <scratch>/wt-accept rev-parse HEAD

Портов 5173/5174 не слушал никто (`ss -ltn` пуст, процессов `vite` нет). Это существенно,
а не педантизм: `playwright.config.ts` держит `reuseExistingServer: !CI`, и живой dev-сервер
из грязного дерева молча подменил бы предмет проверки — набор был бы зелёным по чужому коду.
Playwright поднял оба сервера сам, из `wt-accept`.
