# Журналы цикла проверок

Один файл на цель прогона: `<цель>.md` — например `warehouse-offcut.md`, `review-followups.md`.
Заводит его сам цикл из [`verify.md`](../../skills/verify.md) при первом прогоне по этой цели.

Зачем файл, а не контекст: номер итерации и список «рассмотрено» — единственное, что не даёт
циклу ходить по кругу. В контексте они теряются при перезапуске, и тогда лимит в 30 итераций
превращается в декларацию, а отклонённая находка возвращается как новая.

На каждую итерацию: номер, что запускалось (команда целиком), находки, что починено, состояние
линз. Запись «Л4 — чисто» без команды не считается — см. раздел «Что считается пройденной линзой».
