## Лимиты — как считать

`/usage` показывает проценты, не токены. Лимит выводится разностью по ДЛИННОЙ базе:

| замер | |
|---|---|
| 11.09 ~21:00 | Weekly 10 % |
| 12.09 ~11:40 | Weekly 18 % |
| 12.09 ~12:00 | Weekly 19 % |
| 9 пунктов ↔ 17,7 млн | **недельный лимит ≈ 197 млн** |

Короткая база врёт вдвое (18→19 % даёт 116 млн): проценты округляются до целого.
Окно сессии ≈ 15,1 млн за 5 часов — оценка по ОДНОЙ точке, уточнить при случае.
Счётчик расхода: `python3 /tmp/night-queue-briefs/расход.py` — считает все транскрипты,
включая субагентов (они на уровень глубже, `<сессия>/subagents/`; без них счёт занижен вшестеро).
