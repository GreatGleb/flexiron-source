# Почта flexiron.erp@gmail.com → Telegram

`Code.gs` раз в минуту смотрит «Входящие» ящика и присылает каждое новое письмо ботом
`@flexiron_inbox_bot`: «✉️ Письмо» — от кого, тема, текст и ссылка на письмо в Gmail; вложения — следом
файлами. Спам, архив и письма до включения не пересылаются. Ответить из Telegram нельзя — отвечать в Gmail.

## Установка (один раз, минут 5)

Всё — под `flexiron.erp@gmail.com`, в окне, где вошли только в этот аккаунт (инкогнито или свой профиль
Chrome: с несколькими аккаунтами Apps Script не открывается).

1. **Проект.** https://script.google.com → **Новый проект**. Слева вверху переименовать в
   `Flexiron — почта в Telegram`.
2. **Код.** Стереть всё в `Code.gs`, вставить код из этого файла `Code.gs`, нажать 💾.
3. **Секреты.** ⚙ **Настройки проекта** → **Свойства скрипта** → **Добавить свойство** — две строки,
   те же, что у скрипта заявок:

   | Свойство | Значение |
   |---|---|
   | `TG_BOT_TOKEN` | токен бота (из `frontend_vue/.env.local`) |
   | `TG_CHAT_ID` | id своего чата с ботом |

   **Сохранить свойства скрипта.**
4. **Включить.** Вернуться в **Редактор** (`< >` слева). На панели над кодом в списке функций выбрать
   **`setup`** → **▶ Выполнить**. Google попросит доступ: аккаунт `flexiron.erp@gmail.com` →
   «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → **Разрешить**. Скрипт просит
   чтение почты, внешние запросы (Telegram) и запуск по расписанию.
5. В Telegram придёт **«✅ Пересылка почты flexiron.erp@gmail.com включена»**. Всё.

## Проверка

Отправить письмо со своей почты на `flexiron.erp@gmail.com` — через 1–2 минуты оно придёт в Telegram.
Не пришло — в Apps Script слева **Выполнения**: там каждый запуск и текст ошибки.

## Выключить и включить

- Выключить: выбрать функцию **`stop`** → **▶ Выполнить**.
- Включить снова: **`setup`** → **▶ Выполнить** (письма, пришедшие за время выключения, не пересылаются).

## Как устроено

- Граница «новых» — время последнего пересланного письма (свойство `LAST_TS`, плюс `SEEN_AT_TS` — id писем
  с тем же временем: у Gmail оно с точностью до секунды). Их ставит и обновляет сам скрипт — не трогать.
- Telegram не ответил — граница не двигается: письмо уйдёт в следующую минуту, а уже отправленное
  второй раз не придёт.
- За один запуск — не больше 20 писем, остальные — в следующую минуту.
- Длинное письмо обрезается до предела сообщения Telegram (4096 знаков) с пометкой; ссылка на Gmail остаётся.
- Файл больше 50 МБ бот отправить не может — вместо него строка «только в Gmail». Встроенные в письмо
  картинки (логотипы подписей) не пересылаются.
- Токен бота вырезается из текста ошибок до записи в журнал.
- Лимиты Google для бесплатного аккаунта (90 минут работы триггеров в сутки) запуск раз в минуту выдерживает.
