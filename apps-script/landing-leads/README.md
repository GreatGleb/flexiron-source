# Заявки с лендинга: таблица + Telegram + капча

`Code.gs` принимает заявку с формы лендинга Flexiron и делает по порядку:

1. проверяет поля теми же правилами, что и форма;
2. проверяет капчу Cloudflare Turnstile — токен от формы уходит в Cloudflare вместе с секретным ключом;
3. шлёт сообщение «📝 Заявка с сайта Flexiron» ботом в Telegram;
4. дописывает строку в лист `Leads` Google Таблицы.

Скрипт привязан к таблице и опубликован как веб-приложение. Форма шлёт `POST` с
`Content-Type: text/plain` — так браузер не делает CORS-preflight, который Apps Script не обслуживает.

## Установка (один раз, минут 10)

Всё делается под аккаунтом `flexiron.erp@gmail.com`.

1. **Таблица.** https://sheets.new → назвать её `Flexiron — заявки с сайта`.
2. **Скрипт.** В таблице: **Расширения → Apps Script**. Слева вверху переименовать проект в
   `Flexiron — заявки`. Стереть всё в `Code.gs`, вставить код из этого файла `Code.gs`, нажать 💾.
3. **Секреты.** Слева **⚙ Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство** —
   три строки:

   | Свойство | Значение |
   |---|---|
   | `TURNSTILE_SECRET` | Secret Key виджета Turnstile (из `frontend_vue/.env.local`) |
   | `TG_BOT_TOKEN` | токен бота от @BotFather (из `frontend_vue/.env.local`) |
   | `TG_CHAT_ID` | id своего чата с ботом (число из `getUpdates`) |

   **Сохранить свойства скрипта.**
4. **Публикация.** Справа вверху **Начать развёртывание → Новое развёртывание** → шестерёнка →
   **Веб-приложение**:
   - *Описание:* `заявки`
   - *Запуск от имени:* **Я**
   - *У кого есть доступ:* **Все**

   **Начать развёртывание.** Google попросит доступ: выбрать `flexiron.erp@gmail.com` →
   «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → **Разрешить**. Скрипт просит
   таблицу, внешние запросы (Cloudflare и Telegram) и почту (для необязательного `NOTIFY_EMAIL`).
5. **Адрес.** Скопировать **URL веб-приложения** (кончается на `/exec`) и вписать в `frontend_vue/.env`:
   `VITE_LANDING_LEADS_URL=https://script.google.com/macros/s/…/exec`. Адрес публичный — его увидит
   любой в коде страницы, секретов в нём нет. Пока строка пуста, форма не отправляет, а показывает контакты.

## Проверка

1. Открыть URL веб-приложения в браузере → `{"ok":true}`. Страница входа Google или ошибка доступа —
   в шаге 4 доступ стоит не «Все».
2. `cd frontend_vue && npm run dev` → http://localhost:5173/ → заполнить форму и отправить.
   Должны прийти сообщение в Telegram и строка в лист `Leads` (он создаётся сам при первой заявке).
3. Последний столбец строки — `Telegram`: `ok` — сообщение ушло; `off` — не задан `TG_BOT_TOKEN` или
   `TG_CHAT_ID`; `http 401` — неверный токен; `http 400` — неверный `TG_CHAT_ID` или боту не нажали Start.

Если форма показывает «Не удалось отправить», ответ скрипта — во вкладке браузера *Сеть*:

| `error` | Что не так |
|---|---|
| `captcha not configured` | не задан `TURNSTILE_SECRET` — заявки не принимаются, пока его нет |
| `captcha failed` | Cloudflare не принял токен: не тот секрет или сайт не в списке хостов виджета |
| `captcha unavailable` | Cloudflare не ответил — повторить позже |

## Обновление кода скрипта

**Начать развёртывание → Управление развёртываниями → ✏️ → Версия: Новая версия → Развернуть.**
URL не изменится, `VITE_LANDING_LEADS_URL` трогать не нужно. «Новое развёртывание» даёт другой URL.
Свойства скрипта (шаг 3) при обновлении кода сохраняются.

## Почта (необязательно)

Свойство `NOTIFY_EMAIL` с адресом — ещё и письмо о каждой заявке. Сбой почты заявку не отменяет.

## Лимиты и защита

- Секреты только в свойствах скрипта: в коде сайта их нет, в репозитории тоже.
- Без `TURNSTILE_SECRET` заявки отклоняются: забытая настройка не выключает защиту тихо.
- Капча проверяется до Telegram и до таблицы: бот без токена не порождает ни сообщения, ни строки.
- Сбой Telegram заявку не теряет: строка пишется всё равно, исход — в столбце `Telegram`. Токен бота
  вырезается из текста ошибки до записи в журнал скрипта.
- Лимиты полей — константы в начале `Code.gs`; то же правило в `frontend_vue/src/domain/landingLead.ts`,
  и тест фронтенда сверяет их, так что менять надо в обоих.
- Каждое значение пишется с ведущим апострофом: текст вида `=…` хранится как текст, а не формула.
- Запись идёт под `LockService`; сообщение в Telegram — вне замка, чтобы медленная сеть не держала очередь.
