# Заявки с лендинга в Google Таблицу

`Code.gs` принимает заявки с формы лендинга Flexiron (страница `/`, раздел «Заявка»). Он привязан к
Google Таблице и опубликован как веб-приложение. Форма шлёт `POST` с `Content-Type: text/plain` —
так браузер не делает CORS-preflight, который Apps Script не обслуживает.

## Развёртывание

1. Создайте новую Google Таблицу (например, «Flexiron — заявки с лендинга»).
2. **Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте код из этого файла. Сохраните.
3. **Начать развёртывание → Новое развёртывание**. Тип (шестерёнка) — **Веб-приложение**:
   - *Запуск от имени:* **Я**
   - *У кого есть доступ:* **Все**
4. Нажмите «Начать развёртывание» и разрешите доступ к таблице и к отправке почты. Google предупредит
   о непроверенном приложении: «Дополнительно → Перейти к проекту».
5. Скопируйте URL веб-приложения (заканчивается на `/exec`) и впишите его в `frontend_vue/.env`:
   `VITE_LANDING_LEADS_URL=https://script.google.com/macros/s/…/exec`. Затем пересоберите сайт
   (`cd frontend_vue && npm run build`). Пока строка пуста, форма ничего не отправляет и показывает
   контакты для связи напрямую.

Лист `Leads` создаётся сам при первой заявке, с шапкой
`Дата | Имя | Компания | Контакт | Комментарий | Страница | Браузер`.

## Проверка

Откройте URL веб-приложения в браузере — должно вернуться `{"ok":true}`. Если видите страницу входа
Google или ошибку доступа — в шаге 3 доступ стоит не «Все».

## Уведомление на почту

Без настройки заявки только пишутся в таблицу. Чтобы получать письмо о каждой заявке:

1. В редакторе Apps Script — **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** →
   **Добавить свойство**.
2. Свойство `NOTIFY_EMAIL`, значение — адрес, на который слать письма. Сохраните.

Код при этом менять и переразвёртывать не нужно — свойство читается при каждой заявке. Если письмо
не ушло (например, кончилась дневная квота почты Google), заявка всё равно остаётся в таблице.

## Обновление кода скрипта

**Управление развёртываниями → ✏️ → Версия: Новая версия → Развернуть.** Так URL не изменится, и
`VITE_LANDING_LEADS_URL` трогать не нужно. Если создать «Новое развёртывание», URL получится другой.

## Лимиты и защита

- Сервер проверяет заявку теми же правилами, что и форма: обязательные имя и контакт, длины полей,
  телефон или e-mail. Лимиты — константы в начале `Code.gs`; правило записано в двух местах — там и в
  `frontend_vue/src/domain/landingLead.ts`, и тест фронтенда сверяет их, так что менять надо в обоих.
- Каждое значение пишется с ведущим апострофом: текст вида `=…` хранится как текст, а не исполняется
  как формула.
- Запись идёт под `LockService`, одновременные заявки не перетирают друг друга.
